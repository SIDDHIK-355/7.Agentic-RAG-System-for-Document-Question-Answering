Step 4 — Design 5 Custom Queries

Rules from sir:
✓ Each query must answer correctly WITH the index
✓ Each query must FAIL without the index
✓ At least 2 queries must be SEMANTIC (your words ≠ words in the document)

Example queries for Anthropic/AI corpus

#QueryTypeWhy it works
1"How does Anthropic make sure Claude doesn't lie?"Semantic"lie" → papers say "honesty", "truthfulness", "deception"
2"What happens when you make a model too large?"Semantic"too large" → papers say "scaling laws", "compute", "diminishing returns"
3"What is Constitutional AI and how does it work?"DirectExact topic in corpus
4"How do these papers think about AI causing harm?"Semantic"causing harm" → papers say "safety", "alignment", "RLHF", "red-teaming"
5"What is RAG according to these papers?"DirectRAG paper is in corpus

Queries 1, 2, 4 are semantic — your words don't appear in the papers but the meaning matches.

Step 5 — Prove It Fails Without Index

1. Run all 5 queries with index → save output (these are your WITH traces)

rm state/index.faiss state/index_ids.json state/memory.json
3. Run the same 5 queries again → save output (these are your WITHOUT traces)
Agent should fail, search the web, or give a wrong answer
4. Restore state files (or re-index) and confirm it works again
