Step B — Fetch your documents

Use the agent to fetch each URL and save it. Example command:

uv run agent7.py "Fetch https://www.anthropic.com/research/constitutional-ai-harmlessness-from-ai-feedback and save it as my_corpus/constitutional_ai.md"

Do this for each of your 50 URLs.

Step C — Index your corpus (one command)

uv run agent7.py "Index every .md file under my_corpus/. Confirm how many chunks were indexed."

Step D — Write 5 custom queries

#Your queryRule
Q1Write a question whose answer is in your corpusMust answer correctly WITH index
Q2Write a question whose answer is in your corpusMust answer correctly WITH index
Q3Write a SEMANTIC question (your words ≠ document words)Must be semantic
Q4Write a SEMANTIC question (your words ≠ document words)Must be semantic
Q5Write any question from your corpusMust fail WITHOUT index
What is a semantic query?
Your question uses different words than the document. Example:
— You ask: "How does Anthropic stop Claude from being manipulated?"
— Document says: "adversarial robustness", "red-teaming", "prompt injection defenses"
The words are different but the meaning matches → vector search finds it, keyword search cannot.

Step E — Prove it fails without the index

Run each query WITH index → save output

Then delete state:
rm state/memory.json state/index.faiss state/index_ids.json

Run same queries WITHOUT index → save output
Agent should fail or give wrong/empty answer

Re-index and confirm it works again
