Query G — Synonym Recall (Vector Beats Keyword)

What this query tests: Can the agent find relevant content when the exact words in the question do NOT appear anywhere in the indexed documents?

The Query

"Across these papers, how do they handle the credit assignment problem?"

What is the Credit Assignment Problem?

Simple version: When a system makes many decisions in a sequence and gets a final result — which decision was responsible for that result?

Example: A dog does 10 tricks, then gets a treat. Which trick earned the treat?

In ML: A neural network makes many calculations. When the output is wrong, which weight caused it?

The papers don't use the phrase "credit assignment problem" anywhere. But they all deal with related ideas — gradient flow, reward shaping, intermediate reasoning steps, parameter updates. Vector search finds those related ideas.

Why Keyword Search Would Fail Here

Keyword search for "credit assignment problem":
→ grep across all 5 papers = 0 results
→ BM25 search = 0 results
→ Agent returns nothing useful
Vector search for "credit assignment problem":
→ Query converted to 768 numbers by Ollama
→ FAISS finds chunks with semantically related content
→ Finds: attention mechanism (path length), chain-of-thought (intermediate steps), DPO (reward), LoRA (parameter credit), ReAct (action attribution)
→ Agent synthesizes an answer from 4 out of 5 papers

This is the strongest demonstration of why RAG with embeddings is needed. Keyword search literally cannot answer this query. Vector search can.

How Each Paper Relates to Credit Assignment

PaperHow it relates (even without using the phrase)
Attention (Transformer)Self-attention creates direct paths between positions — shorter paths mean gradients flow more easily (easier credit assignment across long sequences)
Chain-of-ThoughtBreaking reasoning into explicit steps makes each step evaluable — intermediate steps get their own credit
DPOUses human preference data to assign reward — directly addresses which response deserves credit
LoRAUpdates only a small set of low-rank parameters — credit is concentrated on fewer weights making it more precise
ReActInterleaves reasoning and action — each reasoning step is tied to a specific action, making attribution clearer

The Key Lesson

Dense vector search understands meaning.

"Credit assignment" and "gradient flow through reasoning steps" mean related things.
The embedding model was trained on enough text to know this.
So their vectors point in similar directions in 768-dimensional space.
FAISS finds the small angle between them.

Keyword search sees only characters. Vector search sees meaning.
